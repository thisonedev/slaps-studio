# Changelog

Each release has a section here, drafted by `pnpm release` and edited in its release PR.

## [0.1.0] - 2026-10-11

First release of the design studio as a desktop app.

- 62 templates for social posts and threads, with built-in UI kits and a brand kit builder
- Export to PNG, JPG, PDF and SVG
- AI elements painted by image models that run on your machine
- Saved designs and brand kits stored locally
- Profile with a recovery phrase
- Installer and the `slaps-studio` command for macOS, Linux and Windows
